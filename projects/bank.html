Bank Simulation

Daniel Vishnevsky

About

Bank simulation that features account system, deposits, withdrawals and transactions to other accounts. It is fully local using SQLite.

Features

This project features an account system. The passwords are hashed using SHA256 algorithm and stored in the database. After creating an account, the user can edit things like age, username and password or fully delete it.

No real money is used and instead the user can simulate it by depositing and withdrawing it from the bank. The bank is an inaccessible account (unless you know some SQL commands) that simply transfers or receives money. Transferring works in the same manner but you can do it with others instead of just the bank.

There are also ways of checking your balance and transaction history with red and green colors to see where you spent money and where you gained money.
