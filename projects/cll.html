CLL

CLL A high-level interpreted scripting language inspired by Python and C++ made to be comfortable to use. It is a C-like language with a basic standard library that supports functions, loops and arrays. Everything is an expression in the language which makes it pretty unique. You can put a for loop in a variable.

The infamous "Hello, World!" looks like this:

fn main() {
   println("Hello, World!")
}

Factorial example:

fn factorial(n) {
   return n unless n > 1
   n * factorial(n - 1)
}

fn factorial_iterative(n) {
   return for let i = n - 1; i > 1; i-- do n *= i
}

Nth fibonacci number:

fn fibonacci(n) {
   return n unless n > 1
   fibonacci(n - 1) + fibonacci(n - 2)
}

fn fibonacci_iterative(n) {
   return n unless n > 1
   let prev1, prev2, curr = 1, 0

   for let i = 2; i <= n; i++ {
      curr = prev1 + prev2
      prev2 = prev1
      prev1 = curr
   }
   return curr
}

Simple input application:

fn main() {
   let name = input("Input your name: ")
   let age = inputnum("Input your age: ")
   printfln("Hi, {}! You will be {} next year!", name, age + 1)
}

Grade standard deviation calculator:

fn main() {
   let grades = []
   let num = 0
   let sum = 0

   // input all grades
   while {
      num = inputnum("Input grade (-1 to stop): ")
      break unless num != -1
      grades.push(num)
      sum += num
   }

   let average = sum / grades.size()
   let squareSum = 0

   // calculate variance and standard deviation
   for grade in grades do
      squareSum += (grade - average) ** 2
   
   let variance = squareSum / grades.size()
   let stddev = variance ** 0.5

   // output everything
   printfln("Grades: {}", grades)
   printfln("Average: {}", average)
   printfln("Variance: {}", variance)
   printfln("Standard deviation: {}", stddev)
}

SSL

The sequel to CLL - an even simplier scripting language. Although, this one isn't in an usable state like CLL is. One major difference is that CLL is functional-ish while SSL is imperial.

"Hello, World!" example:

fn main()
   println('Hello, World!')
end

Factorial example:

fn factorial(n)
   if n <= 1 return 1 end
   return n * factorial(n - 1)
end

fn factorial_iterative(n)
   z := n // n is constant
   for i in 2 until n
      z = z * i
   end
   return z
end

Development

I started developing CLL in August 2025 to achieve my dream of a real usable programming language and I experimented a lot along the way, making it quite unique from the rest. I love how it turned out but I would be more proud if I got references to work right. Because I failed to get them right, I quit making it.

That happened in September 2025. But somewhere in March 2026 I got the urge again. To create another programming language. And that's when I started working on SSL - it was supposed to be CLL but better. And with references.

And I kind of did achieve that goal. SSL had working references. But I didn't get it in an usable state in the end because I quit. I'm not sure why, but I have a hunch that it was because of Sandbox-2D or AA3.

If you're interested in playing around with these two languages, check out their source code: CLL, SSL. CLL is documented but 8 months have passed since I last touched SSL's source code, so I was too lazy to document it.
