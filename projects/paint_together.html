Paint Together

Daniel Vishnevsky

Local demo. Draw with left click, change brush size with scroll wheel, change color with arrow keys, F - fullscreen

About

Paint Together is a LAN drawing application. It's very simple to use. It's split in two applications - server and client. The server is responsible for retrieving state from all clients, saving it in the history and distributing the changes to all clients.

The client is responsible for displaying and modifying the canvas. The canvas can be modified using a few select colors. It's really primitive but that's the fun of it. SFML is used for the networking while Raylib is used for the graphics.

Development

This is a simple project but I've been wanting to make it for like a year. One day I just decided to do it and it took only like 2 days to do it + a few line change a few months later to make it work in a LAN. Overall a nice project to add to your portfolio.

Later on I added a HTML Canvas demo that does not include any networking at all. Added it just for fun.
