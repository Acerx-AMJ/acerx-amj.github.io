About

Graphics library based on SFML to make writing SFML easier and more comfortable. It handles event boilerplate, a lot of the math and element positioning for the user. It's designed for game development and applications in mind.

void LoadingState::setup_styles() {
   loading_text.set_string("Setting Up Styles...");
   game.initialize_game();
   loading_bar.set_progress(1.0f);
   loading_text.set_string("Loading Done!");
   audio.play_sound("success", 1, 0.75f, 1.25f);
}

Features

This library is easily integratable with SFML. It features a lot of utility UI elements and has a wide variety of managers like asset, audio, navigation, particle, event and animation manager.

To add, it had a lot of utility. Easier to use vector2, vector3, vector4 and vector5 structures with loads of math functions built-in. A dedicated math library, raycasting, colors, camera handler and even a grid for easy element positioning.

The library gives the user multiple options for positioning - either position elements by the top-left corner, the center or the bottom-right corner. You can also position elements by a single side. Each UI element had loads of small utility functions that make life easier. There are also saveable styles for each element.

Hello, World!

#include <CX/AssetManager.hpp>
#include <CX/EventHandler/EventHandler.hpp>
#include <CX/Text/Text.hpp>

int main() {
   sf::RenderWindow window (sf::VideoMode(800, 600), "Hello, CX!");
   window.setFramerateLimit(60);

   cx::EventHandler event (window);
   cx::AssetManager asset;
   asset.load_font("font.ttf");

   cx::Text text ("Hello, World!", *asset.get_font("font"), event.get_center());

   while (window.isOpen()) {
      event.update();

      window.clear();
      text.render(window);
      window.display();
   }
}

Collisions

#include <CX/EventHandler/EventHandler.hpp>
#include <CX/Circle/Circle.hpp>
#include <CX/Rect/Rect.hpp>

int main() {
   sf::RenderWindow window (sf::VideoMode(800, 600), "CX Library");
   window.setFramerateLimit(60);

   cx::EventHandler event (window);
   cx::Circle circle (50.0f, event.get_center(), cx::Color::red());
   cx::Rect rectangle ({50.0f}, {}, cx::Color::red());

   while (window.isOpen()) {
      event.update();

      rectangle.set_center(event.get_mouse_pos());
      rectangle.rotate(event.get_axis(cx::Key::q, cx::Key::e));

      if (rectangle.colliding(circle)) {
         rectangle.set_color(cx::Color::green());
         circle.set_color(cx::Color::green());
      }
      else {
         rectangle.set_color(cx::Color::red());
         circle.set_color(cx::Color::red());
      }

      window.clear();
      circle.render(window);
      rectangle.render(window);
      window.display();
   }
}

Raycasts

#include <CX/EventHandler/EventHandler.hpp>
#include <CX/Ray/Ray.hpp>
#include <CX/Rect/Rect.hpp>

int main() {
   sf::RenderWindow window (sf::VideoMode(800, 600), "CX Library");
   window.setFramerateLimit(60);

   cx::EventHandler event (window);
   cx::Rect rectangle ({50.0f}, event.get_center(), cx::Color::red());
   cx::Ray ray ({}, {0.0f, 1.0f}, 200.0f);

   while (window.isOpen()) {
      event.update();

      ray.set_origin(event.get_mouse_pos());
      ray.rotate(event.get_axis(cx::Key::q, cx::Key::e) * event.get_dt());

      rectangle.set_color((ray.colliding(rectangle) ? cx::Color::green() : cx::Color::red()));
      const auto reflected = ray.reflect(rectangle);

      window.clear();
      rectangle.render(window);
      ray.render(window);
      if (reflected.has_value()) {
         reflected->render(window, cx::Color::gray());
      }
      window.display();
   }
}

Planets

#include <CX/EventHandler/EventHandler.hpp>
#include <CX/Circle/Circle.hpp>
#include <CX/Math/Trigonometry.hpp>

int main() {
   sf::RenderWindow window (sf::VideoMode(800, 600), "CX Library");
   window.setFramerateLimit(60);

   cx::EventHandler event (window);
   cx::Circle star (100.0f, event.get_center(), cx::Color::yellow());
   cx::Circle planet1 (20.0f, star.get_center() - cx::Vec2f(0.0f, 150.0f), cx::Color::green());
   cx::Circle planet2 (10.0f, star.get_center() - cx::Vec2f(0.0f, 125.0f), cx::Color::red());
   float frame = 0.0f;

   while (window.isOpen()) {
      event.update();
      frame += event.get_dt();

      star.set_scale(cx::Vec2f(1.0f + cx::sin(frame * 0.6f) * 2.0f * event.get_dt()));

      planet1.set_scale(1.0f + (planet1.get_center_y() / event.get_width()) * 3.0f);
      planet1.move(3.0f * cx::cos(frame * 0.6f), 1.6f * cx::sin(frame * 0.6f));

      planet2.set_scale(1.0f + (planet2.get_center_y() / event.get_width()) * 3.0f);
      planet2.move(4.0f * cx::cos(frame * 1.2f), 2.0f * cx::sin(frame * 1.2f));

      window.clear();
      star.render(window);
      planet1.render(window);
      planet2.render(window);
      window.display();
   }
}

Development

I started making this somewhere in December of 2024 to make writing SFML games and UI easier and it was my first library ever. I rewrote Astral Surge in CX Library and eventually did the same with Pong to see its capabilities. Since I was working on different games in parallel, I could easily see what features were missing, which needed to be tweaked and which were useless.

I stopped developing it at the same time I stopped developing Astral Surge. You can see the source-code on Github and a few videos are available at my old Youtube channel.

The main point of this library was to make doing any tiny thing really easy in SFML. It's kind of like Tailwind CSS for CSS. The library's sole purpose was to make life easier and I feel like it served it well. I stopped development solely because I got tired from making it. I was developing it for half a year so no surprise there.
