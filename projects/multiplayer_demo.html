About

Simple 2D demo where you can chat with friends in a LAN. It's a top-down 2D demo with avatar customization and chatting.

Development

Right after creating chatroom that used only TCP sockets, I decided it would be beneficial to learn UDP as well. In the end, I also implemented a chat with TCP sockets, meaning the server handles both TCP and UDP. A pretty good learning project.

In October 2026 I polished the source-code, added a customization feature and made it work outside of just your computer. The source-code is available on Github.
