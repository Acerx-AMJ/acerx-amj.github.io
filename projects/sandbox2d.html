About

Sandbox survival game where you can build, destroy and explore. It provides procedurally generated worlds with different biomes and unique experiences. Made with C++ and Raylib.

Source Itch.io Youtube

Features

This sandbox game features procedurally generated worlds with different biomes, survival and creative modes and physics. Why not try it out yourself? It's free!

It loads all tiles, furniture, items, drop tables and even liquids from custom human-readable file formats and handles all of their interaction in the game. Yes, you can create your own liquids if you'd like to. There's a default config but you can edit it to your own liking. Basically a sandbox game engine.

Development

I started working on this game for the sole reason of improving my skills and learning how to structure and design a big game. In the end, it served its purpose well, with this being one of my biggest projects. Kind of funny knowing that at first I was like "fuck it, let's remake Terraria".

The development was rocky with a lot of project switching and a burn out, but this project will always stay in my heart, just like Astral Surge, and I'd say I still will work on it here and there. Until it's finished. But looking back at this project, it looks good. Like really good. Like a real game. Weird that I have the least to say about my biggest project.
