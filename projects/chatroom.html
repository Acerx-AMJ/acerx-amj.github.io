About

CLI chatroom that you can use to chat with your friends in a LAN. This was my first networking project. You technically can chat outside of a LAN, but your router will most likely block that from happening by default.

Development

I wanted to challenge myself and create something outside of my usual interests and this just seemed like a good project to do so. I followed one of the SFML networking tutorials on their documentation site and adjusted it for a chatroom.

In October 2026 I slightly edited the code to be more readable and to allow connection outside of this machine. The newest version is available on Github here and the old version here. Not much else to say about this project. Go make it yourself.
