Core IT Principles

Daniel Vishnevsky

I want to share some principles I personally find useful in IT.

  1. Fuck around and find out
  2. Practise. Tutorials are for nerds
  3. Data doesn't exist unless it's stored in atleast 2 different places
  4. If it's broken, try turning it off and back on
  5. If it's still broken, give it the middle finger and try again
  6. If it works, don't touch it (I'm guilty of not following this)
  7. Fuck Microsoft
